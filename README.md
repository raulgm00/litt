# LITT · sitio borrador + propuesta de piloto (WeSoft)

- `index.html` — qué es LITT (Laboratorio de Innovación Turística Territorial), a partir de lo que comparte su impulsora.
- `propuesta.html` — propuesta de piloto de WeSoft: identidad turística territorial de Cocula, Jalisco.
- `PROPUESTA.md` — la propuesta en texto, con fuentes.
- `assets/` — estilos compartidos (`litt.css`) y efectos del skill web-premium.
- `img/` — imágenes y video ilustrativos generados con IA (Z-Image Turbo y Wan 2.2 en local).

Sitio estático, sin build. Para publicarlo con GitHub Pages: Settings → Pages → Deploy from a branch → `main` / `(root)`.

Borrador pendiente de revisión y aprobación de LITT antes de compartirse públicamente.
